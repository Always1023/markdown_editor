## 过程记录
- **盘点发现：入口 UI 已随编辑器装配落地**：意图层写「useRichMarkdownSearch 已迁移、无入口 UI（现状）」——盘点时发现 RichMarkdownEditorSurface 已内置 RichMarkdownSearchBar 全套接线（Ctrl+F / Ctrl+H 快捷键经 app-keyboard-router，计数 / 上下条 / 替换 / 高亮全通）。本 issue 的实际工作＝把冻结的 A1-A3 落成机检探针证明该链路，产品代码零改动。意图层目标（能搜能换）达成，无范围变化。
- **探针断言细节**：Ctrl+F 须以编辑器内元素为 target 派发（app-keyboard-router 的 openSearch 要求 targetInsideEditor）；搜索条按钮按 DOM 序取（prev / next / close / replace / replace-all）；替换结果从 store.editorDrafts 断言（App onContentChange 已写入草稿）。
