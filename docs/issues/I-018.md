- **死集（DEAD）549 文件**：从活入口与测试根都不可达——本 issue 删除对象
- **test-only 岛 501 模块**：只被测试引用，但锚定了 3 个活代码测试（save-queue CAS / dirty / races）与 PanZoom 测试——**不动**（删它们要重写活测试的 fixture，另记想法）
- **误判纠正**：`rich-markdown/review/*`（19 文件）与 diff-comments store 切片全在活编辑器链上，不是死代码（I-003 待决的猜测不成立）；`src/preload/**` 类型面是 AGENTS 第 3 条的契约载体且在 tsc 程序内——**保留**
