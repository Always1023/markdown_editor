## 目标
- 意图：想让 demo 编辑真实磁盘上的 Markdown 文件（目标）；现在文档驻内存、Ctrl+S 只更新 state（现状）；不做则「编辑器能保存」这一最小产品闭环不存在（代价）
- 行为：启动时打开工作目录下的 welcome.md（无则创建示例文档）；编辑 → 300ms 防抖 → 自动保存 / Ctrl+S 即时保存走 writeIfUnchanged 写盘；外部程序修改该文件 → 磁盘变更事件 → 编辑器显示外部修改横幅（不静默覆盖）
- 机制：组装层调用已迁移的 save / flush / autosave 链（pending-flush / stale-view-edit / discard-epoch 语义随内核生效）；watch 事件接 store 的磁盘基线更新
