## 过程记录
- **自动保存生命周期与首标签解耦**：目标＝关闭 welcome.md 后其余标签仍自动保存；现状＝startDemoFileIo 把 attachEditorAutosaveController 挂在首个文件生命周期上，dispose 即拆。试错＝App 包一层 dispose 跳过 detach（语义绕）。答案＝DemoFileIoOptions 增 `attachAutosave?: boolean`（默认 true 保住 I-009 契约），App 外壳传 false 自己在 mount 时挂全局、unmount 时拆；I-009 探针零改动。
- **TabBar 数据源**：目标＝标签与打开文件一致；现状＝App 层自维护 controllers Map，与 store.openFiles 是两份事实。答案＝TabBar 从 store.openFiles 投影（worktreeId = demo::local 过滤），controllers Map 只管 IO 生命周期（fs 订阅 / saveNow），激活态仍由 App 层 activeFileId 驱动（编辑器 remount 按 key=fileId）。
- **全局 store 跨测试累积**：探针首跑出现 7 个标签（前几例的 openFiles 残留）。答案＝beforeEach 用 `useAppStore.setState(useAppStore.getInitialState(), true)` 回滚初始态再装配。
- **filePath 分隔符漂移**：store 内是 workDir + '/' + 文件名（混合斜杠），探针按纯反斜杠 join 精确匹配落空。答案＝探针比较前 replace(/\\/g, '/') 归一化。
- **已知边界（记录，不在本 issue 展开）**：标签切换按 key 重挂编辑器，undo 历史随切换重置（多 buffer 深化留阶段 4 后）；外壳文案暂为中文硬编码（I-009 起装配层如此），接 useTranslate 记为看板想法。
