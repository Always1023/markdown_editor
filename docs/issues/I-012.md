## 目标
- 意图：想同时开多个文件并快速切换（目标）；现在只有单文件 demo 页（现状）；不做则对照产品最基本的多文档体验缺失（代价）
- 行为：顶部标签栏列出打开的文件；点击切换；关闭按钮（dirty 时确认）；dirty / 保存态在标签上可见
- 机制：store 的 unifiedTabs（B1 已迁移）+ openFile / closeFile 动作 + TabBar UI 组件接线
