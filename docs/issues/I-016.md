## 过程记录
- **updateSettings 原注释即欠账**：compat 层 updateSettings 注释「设置持久化在阶段 3 接入；先本地合并」——本 issue 兑现：合并后 persistAppSettings 落 localStorage；App 启动 install 之后 hydrateAppSettings 恢复（顺序保证 hydrate 覆盖 demo 引导的 editorAutoSave:true）。坏快照忽略并清除，不阻塞启动。
- **缩放 setter 补空**（2 档，记 DEVLOG `[补空白]`）：store 只有 editorFontZoomLevel 字段没有 setter（Orca 在 ui-slice），本产品 compat 层补 setEditorFontZoomLevel（Orca ui-slice-persistence-actions 同款、逐字语义：直接 set 不 clamp，会话级不持久化）。
- **A3 探针首次跑挂**：重载模拟渲染第二只 App 前没卸载第一只 → settings-open 双命中。答案＝harness.unmount() 后再渲染。
