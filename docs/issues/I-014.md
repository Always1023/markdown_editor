## 过程记录
- **面板装配直接用迁移件**：目标＝TOC 面板可用；现状＝RichMarkdownEditorSurface 已内置 MarkdownTableOfContentsPanel + navigateToTableOfContentsItem，只差 showTableOfContents / onCloseTableOfContents 两个 prop 接线。答案＝App 层加「目录」按钮（仅 rich 模式显示）写 store.markdownTableOfContentsVisible[fileId]，编辑器 prop 跟随；不新写面板。
- **A1 缩进断言语义**：首版断言「三行缩进递增」失败——父行内缩由 chevron 列提供（paddingLeft 相同），只有叶子行 paddingLeft 更大。答案＝断言「标题按文档顺序出现 + 叶子行缩进 > 父行」，语义正确且不咬死实现常量。
- **A3 文本断言**：标题同时出现在 TOC 与编辑器正文，getByText 双命中抛错。答案＝getAllByText > 0。
