## 目标
- 意图：想让粘贴的截图自动存进磁盘并在文档里引用（目标）；现在 blob 管线到 clipboard.saveImageAsTempFile / importExternalPaths 处断链（无主进程实现），粘贴失败静默（现状）；不做则「粘贴图片自动落盘」这一核心卖点不成立（代价）
- 行为：粘贴截图 → PNG 转换 → 主进程落临时文件 → importExternalPaths 拷入文档同目录 → markdown 引用替换为本地文件名 → 图片经本地读取通道显示
- 机制：内核管线（rich-markdown-blob-image-paste 等）已迁移并测试通过，本 issue 只接主进程两端（saveImageAsTempFile + importExternalPaths）与显示读取（local-image-src-reader 依赖的 fs 通道）；目录语义跟随 Orca（文档同目录）
