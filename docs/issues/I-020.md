## 目标
- 意图：产出可安装的 Windows 成品（目标）；`package` script 已有但 electron-builder 无配置（现状）；不做则交付只有源码，非开发者装不上（代价）
- 行为：`pnpm package` → dist/ 产出 NSIS 安装包与 win-unpacked 可执行；安装包静默安装 / 卸载闭环；打包版应用可启动
- 机制：electron-builder.yml（appId / productName / files 白名单 out/** + package.json / nsis target）；electron-vite 三段构建产物进包

## 边界（不做）
- 不发布 Releases：无远程仓库（人未定发布渠道），安装包只落本机 dist/。
- 不自制应用图标：无图标时 electron-builder 用默认 Electron 图标，观感属 A5 人验；自制图标记想法不顺手做。

## 过程记录
- **产物体积 ~149MB 安装包 / ~227MB 解压**：根因是 64 个生产依赖整包进 asar（externalizeDepsPlugin 让 main/preload 走 node_modules）+ mermaid / katex / highlight.js / emoji-picker 大件。demo 阶段接受；瘦身（依赖审计 / asar smart unpack）记想法不顺手做。
- **图标用默认**：electron-builder 警告「application icon is not set」，与 issue 边界一致（自制图标记想法，观感归 A5 人验）。
- **A4 的证据形态**：不逐条列 asar 内容，直接以 A2「打包版可启动」为证——入口 out/main/index.js 在包内且能拉起整条 main→preload→renderer 链，比列举更强。
- electron-builder 首跑下载 nsis / 7zip 工具链（~几十 MB，缓存于 %LOCALAPPDATA%/electron-builder/Cache），后续打包不再下载。

## 自验
- A1 \`pnpm package\` → exit 0；产物：dist/markdown_editor Setup 0.1.0.exe（156,045,199 字节）、dist/win-unpacked/markdown_editor.exe（237,866,496 字节）+ blockmap，尺寸区间断言（10MB~800MB）通过。
- A2 运行 win-unpacked/markdown_editor.exe → 进程出现、窗口标题 **markdown_editor**，结束后 Stop-Process 清理。
- A3 静默闭环：Setup /S -Wait → %LOCALAPPDATA%\Programs\markdown_editor\markdown_editor.exe 存在（237,866,496 字节）→ Uninstall /S -Wait → 目录消失（UNINSTALLED-CLEAN）。副作用与清理：per-user 安装无需提权；冒烟产生的 %APPDATA%/markdown_editor userData 已删除。
- A4 electron-builder.yml 四项齐备（appId / productName / files: out/** + package.json / nsis）；入口在包内由 A2 启动成功背书。
- **安装向导截图（2026-11-22，PrintWindow 实拍）**：oneClick NSIS 窗口（387x156，标题「markdown_editor 安装」，文案「正在安装，请稍候…」+ 进度条）——启动即装、无确认页；中断残留（半截安装目录）经静默卸载 + 目录删除清理。截图存临时目录 me-acceptance/installer-wizard.png。
- **卸载入口行为机检结论（2026-11-22）**：oneClick 卸载器无确认对话框、无可见窗口（枚举 8.4s 无命中）——启动即静默卸载，完成后文件全清（实测目录 0 项）；空目录短暂被 NSIS temp 句柄占用（卸载器已知行为，内容为 0、无系统影响，句柄释放后自然消失）。「卸载入口」的机检实质已由 A3 静默闭环 + 本条行为断言覆盖；无 UI 可截即如实记「无窗口」。
- 向导截图期间发现并修正一处事实：oneClick 安装启动即开始安装（无「立即安装」确认页），中断需杀进程——A3 的 /S 与此行为一致。
- **打包版视觉证据**：CDP 连打包版 exe 截三模式截图（mode-rich / mode-source / mode-preview.png，临时目录 me-acceptance），排版均正确；重生成：`node scripts/screenshot-modes.cjs 9222 <输出目录>`。
- 打包基线：本分支（B4 链）含 I-018 死代码删除与 I-019 文档。
