# I-021 · bug · 打包版首启白屏修复 + 免安装 portable 产物

**批次**：B5 · **关联**：I-020（人验打回）· **分支**：I-021-portable-white-fix

## 三层目标

**意图**：成品在人的真机上双击就能用，不白屏；并且有不装就能跑的版本。

**行为**：安装版 / portable 版普通启动（无调试参数）出现编辑器界面；渲染进程崩溃或主框架加载失败时自动恢复并有日志可查；新增单文件 portable exe 免安装产物。

**机制**：`app.disableHardwareAcceleration()`（文本编辑绘制不依赖 GPU 合成，稳定性优先）+ `did-fail-load` 主框架重试（≤3 次）+ `render-process-gone` 自动 reload（≤3 次）+ 主进程生命周期写 `userData/main.log`（失败可见可行动）；electron-builder win targets 增加 `portable`。

**bug 三要素**：
- 期望行为：双击安装版 / portable exe → 编辑器界面出现。
- 实际行为：人首启安装版（oneClick 装完即启）只见白窗无内容（截图留本文件末尾备注）。
- 不修的代价：成品在真机上不可用，交付被拒。
- 复现：人报告 + 截图；本机 CDP 复跑 DOM 已挂载、界面完整渲染（不稳定复现）→ 指向首启时序（装完即启 + 杀软首扫大文件拖慢解析）或 GPU 合成失败，按工程手段一并堵死。
