## 目标
- 意图：想编辑整个文件夹里的笔记而不只一个 welcome.md（目标）；现在启动只开单文件，无目录浏览（现状）；不做则多文件产品闭环不存在（代价）
- 行为：侧栏显示当前根的文件树（递归 md）；点击文件打开进编辑器；「打开文件夹」按钮换根；根下新增 / 删除 md 后树自动更新（fs:changed）
- 机制：listMarkdownDocuments（I-007 ✓）+ watchWorktree（I-008 ✓）+ dialog 选目录 + 运行时根注册（requirePathInWorkRoots 放行新根）
