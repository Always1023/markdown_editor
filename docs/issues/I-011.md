## 过程记录
- **窗口聚焦抛未捕获异常**：目标＝编辑器聚焦时上报窗口 chrome；现状＝迁移件硬调 `window.api.ui.setMarkdownEditorFocused`，本产品 preload 只接线 fs / runtime / app 三面，聚焦即 TypeError（app-demo-render 探针跑出 unhandled error，真机同样会踩）。试错＝往探针 stub 补 ui 面（治标，真机仍缺）。答案＝`onFocus`/`onBlur` 改可选链调用并留注释（缺通道跳过聚焦遥测），编辑行为不受影响。
- **两套工作根注册表不同源**：目标＝「打开文件夹」选中的目录对文件 IO 与 runtime-call 同时可用；现状＝`requirePathInWorkRoots`（fs:* 通道越权检查）只认 MARKDOWN_EDITOR_ROOTS，`worktrees:register`（runtime files 路径解析）是另一张表。答案＝files.ts 增 `addRuntimeWorkRoot`（进程内 Set，并入 `localWorkRoots()`），换根时渲染端同时调 `fs:chooseWorkDir`（主进程注册 FileService 根）与 `worktrees:register`（runtime-call 根），两条链一起放行。
- **探针初始空列表**：A3 / A4 首轮超时——树停留在「还没有 .md 文件」空态占位。原因＝测试没人创建初始文件，断言却等 welcome.md。答案＝两个探针先写 welcome.md 再渲染。
