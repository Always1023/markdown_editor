## 过程记录
- **HTML 生成选 marked 而非预览 DOM 序列化**：目标＝导出结果可独立打开且含标题 / 表格节点；现状＝预览树是 React 组件，没有现成的 HTML 字符串出口。试错＝从预览 DOM 取 innerHTML（模式相关：source 模式下没有预览 DOM）。答案＝`marked`（已在依赖里，markdown-round-trip 同源）同步 parse + 内联最小样式包成完整文档，任何模式下导出内容一致。
- **导出落盘绕开工作根越权检查是有意的**：fs:writeFile 有 requirePathInWorkRoots 保护（防渲染端任意写）；导出路径来自系统保存对话框（用户选择即授权），exportDocument 走独立的 fs/promises 写入，在 ipc.ts 注释里写明差别。
- **printToPDF 需要真实渲染**：隐藏 BrowserWindow 加载临时 HTML 文件（写进 os.tmpdir、用完即删）→ printToPDF → Buffer 落盘。探针经 setPdfPrinter 注入替身，真实管线由 A5 人验覆盖。
- **stub 传参遗漏**：demo-window-api 的 chooseExportPath 调 deps 时没传 args，A3 的 dialogArgs 断言拿到 undefined——探针先抓住（红）再修，验证了「对话框参数透传」这条链。
