## 目标
- 意图：想把笔记分享为 HTML / PDF（目标）；无导出能力（现状）；不做则交付面缺失（代价）
- 行为：顶栏「导出」按钮 → HTML（preview 渲染 + 内联样式落盘）/ PDF（Electron printToPDF）；系统保存对话框选位置
- 机制：markdown-preview 渲染 → HTML 字符串；webContents.printToPDF；dialog 保存（主进程 IPC）
