## 目标
- 意图：想按场景选编辑方式——富文本所见即所得、纯源码、只读预览（目标）；现在只有 rich（现状）；不做则源码党与分享场景缺席（代价）
- 行为：工具切换 rich / source / preview 三模式；source 用 Monaco（动态 import，AC-08）展示原始 md，可直接编辑写盘；preview 只读渲染；往返内容一致
- 机制：markdown-preview 渲染树（已迁移）+ monaco-editor 0.55.1（动态 import）+ store editorViewMode
