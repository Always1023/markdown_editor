# 设计系统：markdown_editor（暂名）

> 数值的唯一真源是代码里的语义变量：src/assets/main.css 的 `--*`（Tailwind v4 @theme + shadcn 变量表）。
> 本文件只写约定与指向，不抄数值。

## 1. 取用顺序
本项目约定 > 《前端设计规范》；冲突且造成实际问题时，按 `AGENTS.md` 第 3 节判档，不擅自改。
本项目约定的最大来源是 Orca 的 rich-markdown-editor.css（迁移件）：编辑器内部的视觉以它为准，外壳（文件树 / 标签栏 / 状态栏）跟随同一套语义变量。

## 2. 界面结构
- 页面 / 导航：单窗口。左：文件树 / TOC 面板；中：标签栏 + 编辑区；底：状态栏（保存态 / 模式 / 缩放）；右上：设置抽屉
- 主流程：打开文件夹 → 文件树点文件 → 新标签打开 → render-mode 自动裁决渲染方式 → 编辑 → 自动保存（状态栏可见）
- 操作触发什么：文件树点击 → runtime 读文件 → 编辑器载入；模式切换 → 重开文档为对应模式；`/` 与 `[[` 触发补全浮层
- 空 / 加载 / 错误：空 = 「打开文件夹」引导页；加载 = 编辑器骨架；错误 = toast（sonner）+ 状态栏标记，不用静默降级伪装正常
- 每屏的块序与主次：**不写在这里**——以各 issue 的「界面结构骨架」为准；本节只记页面级组织

## 3. 色
- 主题色：中性底 + 少量 accent（跟随迁移来的变量表）；提醒色独立成支
- 语义色：成功 / 危险 / 说明 → 变量表对应项
- 中性底与文字、描边：用 shadcn 默认灰阶（变量表已随迁移件就位）
- 明暗两套：有；class 切换，跟随设置（F11）
- 对比度：首期手工核对编辑区正文与状态栏两处

## 4. 字与尺寸
- 字号刻度、行高、字重：正文 = 系统栈；代码 = `--font-mono` 与 `--markdown-code-font-family`；编辑区缩放 = `--editor-font-zoom-level`（状态栏控件驱动）
- 间距刻度、圆角刻度（`--radius-*`）、断点：全在变量表；桌面应用无响应式断点

## 5. 组件
- 自己写哪些、用库哪些：shadcn 子集（button / tooltip / popover / dropdown-menu / input / command）+ sonner；编辑器内部控件（表格控件、斜杠菜单、搜索框）随迁移件
- 本项目不许的用法：不新增与 shadcn 重复的组件；编辑器浮层不用原生 title 提示

## 6. 视觉语言
- 跟随 Orca 编辑器视觉：克制、内容优先、低噪
- 动效强度：低——沿用迁移 CSS 的既有过渡，不新增动效
