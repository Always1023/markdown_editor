# PRD：markdown_editor（暂名）

## 一句话
一个「丝滑」的本地 Markdown 桌面编辑器：把 Orca（MIT）验证过的编辑子系统抽成独立产品，怎么编辑都不重排你手写的格式。

## 做
| 编号 | 需求 | 说明 |
|---|---|---|
| F1 | 富文本所见即所得编辑 | TipTap WYSIWYG；300ms 防抖序列化提交 + 块级源码保留：未触碰区域字节级不变 |
| F2 | 打开本地 .md 文件与文件夹 | 文件树浏览；含表格 / 数学 / details / HTML / 中文 / 大文档的都能开 |
| F3 | 三种渲染模式自动裁决 | rich / source（Monaco）/ preview；含原始 HTML、脚注、引用链接的文档自动降级 source，防损坏 |
| F4 | 多标签 | 同一窗口多个文档标签；脏状态可见 |
| F5 | 保存与自动保存 | 保存队列走 compare-and-swap 写（writeIfUnchanged）；外部程序改了文件不覆盖，出现横幅 |
| F6 | 图片粘贴与插入 | 粘贴图片写入工作区 assets 目录；文件对话框选图；本地 blob 缓存 |
| F7 | 双链与导航 | `[[` 补全、TOC 面板跳转；http 链接走系统浏览器，.md 链接打开标签 |
| F8 | 导出 HTML / PDF | 当前文档导出 |
| F9 | 全局搜索替换 | 打开的文件夹范围内 |
| F10 | 中英双语界面 | i18n，zh / en 全覆盖 |
| F11 | 设置 | 拼写检查、字体缩放、默认模式、深浅色 |
| F12 | 编辑子系统全覆盖 | 数学公式（KaTeX）、代码高亮（lowlight）、mermaid 图表、details 折叠、表格（Tab 导航）、任务列表、斜杠菜单、emoji |

## 不做
- review 标注、引用上标 citations（迁移时整体摘除，对应架构红线 AC-07）
- 多主机 / SSH 远程运行时、combined-diff（单机本地文件）
- 云同步、账号、多人协作（使用主体是个人用户，各用各的）
- 移动端、Web 版
- 自更新器（第一期 GitHub Releases 直链 + 手动下载换版本）
- 应用内数据库（用户的 .md 文件就是数据，见 ARCHITECTURE 数据流）

## 成功标准
- round-trip 保真可机检：含表格 / 数学 / details / HTML / 中文的测试文档，编辑前后未触碰区域字节级不变；重复打开 / 保存 10 次无格式漂移
- 迁移保留子集的单测全绿（`pnpm test`）
- 本人用它写笔记连续 2 周不弃用（推荐默认，待确认）
